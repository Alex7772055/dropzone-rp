# DROPZONE RP v4

Игровой сайт с виртуальными кейсами, анимацией открытия в стиле рулетки, инвентарём, ежедневной наградой, рейтингом и админ-панелью. Только виртуальные монеты, без денежных ставок.

## Локальный запуск
1. Установи Node.js 20 или новее.
2. В этой папке выполни `npm install`.
3. Задай `SESSION_SECRET` и `ADMIN_KEY` как переменные окружения.
4. Запусти `npm start` и открой `http://localhost:3000`.

## Важно про сохранение аккаунтов на Render
Аккаунты, баланс и инвентарь сохраняются в JSON-файл `data.json`. На хостинге с временной файловой системой файл может исчезнуть при пересоздании/переразвертывании сервиса. Для надёжного сохранения подключи постоянный диск в Render (если он доступен твоему тарифу) с точкой монтирования `/var/data` и добавь переменную окружения `DATA_FILE=/var/data/data.json`. После этого сделай deploy. Если тариф не поддерживает постоянный диск, потребуется внешняя постоянная база данных; один только перезапуск кода не может гарантировать сохранность файла на временном диске.

Смена `SESSION_SECRET` сбрасывает действующие сессии, поэтому пользователям может потребоваться войти заново, но их аккаунты останутся в `data.json`, пока сам файл хранится на постоянном диске.
